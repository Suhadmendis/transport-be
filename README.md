# transport-be

Backend data layer for the Transport Fleet Management mobile app, powered by [Supabase](https://supabase.com).

This repository contains:
- PostgreSQL table schemas (run in the Supabase SQL editor)
- Seed data JSON files for all four entities (Drivers, Vehicles, Cleaners, Items)
- Full API reference for the Supabase REST endpoints used by the mobile app

See [BACKEND_SPEC.md](./BACKEND_SPEC.md) for complete setup instructions and API reference.
